# 公共基础工具

`step1_common.py` 包含跨阶段使用的候选提示词构造、文件指纹、温度拟合和基础评测函数。
名称保留 step1 前缀，是为了兼容已有实验，不代表只允许 Step 1 使用。
它是被导入的工具模块，没有需要单独执行的实验命令，也没有独立实验结论。

Step 1 的 probe 训练、Step 2 的模型加载/评估等仍放在各自所属阶段，允许后续阶段复用。
只有语义上独立于某一步的稳定功能才逐步抽到 common/，不要为了目录整齐复制代码。

改公共代码会影响多个阶段，并可能改变已锁定的代码哈希。
先检查运行任务和依赖方，变更后验证所有受影响入口；不得覆盖历史实验协议。
当前搬迁仅改变文件位置，没有修改任何实验 Python 源码字节。

`runtime_paths.py` 由统一入口调用：定位迁移后的指纹源码文件，仍计算实际字节哈希。
不得用它覆盖哈希值、忽略协议差异或解析 scripts 目录之外的缺失文件。
