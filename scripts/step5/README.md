# Step 5：决策级提前退出（可选，尚未实施）

## 目的

对容易的问题少循环，对困难的问题多循环，研究决策质量与计算成本的取舍。
这与“只在高置信度样本上回答”的拒答策略不是同一件事。

## 使用状态

尚未实现执行入口；当前状态及证据要求见 [result.md](result.md)。

## 实施顺序

1. 先使用已缓存的每轮预测，离线比较最大概率、Ouro 门值与学习型风险头。
2. 风险头用 train 内预留 group 或 out-of-fold 预测拟合；阈值在 validation 内
   再分 policy-fit/check，不使用 test/ood 训练或选择策略。
3. 离线结果若支持继续，再实现逐轮 forward，在满足退出条件时真正停止计算，
   测量整道题全部候选的实际延迟和计算量。

## 必须避免的误解

当前 Ouro forward 会先算完所有轮次。离线选择第二轮只能报告质量与理论轮数，
不能声称降低了真实延迟。每道题必须聚合所有候选的信息后统一退出，
不能混合不同候选在不同深度的未对齐分数再做 softmax。

计划与指标约定见项目根目录 plan.md 的 Step 5。实现后在本页补运行命令，在result.md记录结论。
